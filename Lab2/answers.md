## Контроль расчётов ipcalc

```
ipcalc 10.12.12.0/24
ipcalc 10.12.13.0/25
ipcalc 10.12.13.128/27
ipcalc 10.12.13.160/27
ipcalc 10.12.13.192/30

ipcalc 120.13.120.96/29
ipcalc 120.13.120.104/29
ipcalc 120.13.120.112/29
ipcalc 120.13.120.120/30
ipcalc 120.13.120.124/30
```

Каждая команда подтверждает сетевой адрес, широковещательный адрес и диапазон доступных узлов, совпадающий с табличными расчётами.

### Порядок проверки

1. Устанавливаем ipcalc (на Fedora: `sudo dnf install ipcalc`).
2. Перед защитой запускаем по очереди команды из списка выше и сверяем `Network`, `Broadcast`, `HostMin`, `HostMax`.
3. При необходимости демонстрируем соответствие с таблицами.

### Понятийный минимум

- **IP-адрес** — уникальный идентификатор узла в сети (формат a.b.c.d).
- **Маска** — определяет границу между сетевой и хостовой частью адреса.
- **IP-сеть** — адрес с нулевой хостовой частью, обозначает весь сегмент.
- **Broadcast** — адрес с единицами в хостовой части, используется для рассылки всем узлам сегмента.
- **Определение границ** — применение маски к IP-адресу даёт сетевой адрес; добавление единиц в хостовую часть даёт broadcast; диапазон узлов — от Network+1 до Broadcast−1.
